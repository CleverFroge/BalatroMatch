# 《消除小丑牌》(Balatro Match) 游戏设计文档 (GDD)

## 一、 游戏概述
- **游戏名称**：《消除小丑牌》(暂定) / Balatro Match
- **核心概念**：**四消 (Match-4) + 肉鸽 (Roguelike) + 构筑 (Deck-building)**。
- **设计愿景**：将《小丑牌 (Balatro)》中极具成瘾性的**"基础规则 + 被动遗物打破规则 + 疯狂的数值膨胀 (Chips x Mult)"**体验，平移到受众更广、更直观的"四消"玩法中。

## 二、 核心循环 (Core Loop)
1. **挑战盲注 (Blinds)**：玩家进入一个关卡，目标是在有限的**"剩余步数 (Hands)"**内，达到指定的**"目标分数 (Target Score)"**。
2. **局内消除与算分**：通过移动方块达成消除。每一次消除都会触发对应的基础分数和倍率，结合玩家持有的"小丑牌 (Jokers)"，打出高额分数。
3. **结算与经济**：若步数耗尽未达标则 Game Over（重头开始）；若达标，则根据关卡基础奖励和剩余的步数奖励结算**"金币 (Gold)"**。
4. **商店构筑 (Shop)**：过关后进入商店，花费金币购买随机刷新的小丑牌，扩充或强化自己的被动能力（最多携带 5 张），然后迎接分数要求更高的新盲注。

## 三、 核心玩法机制 (Mechanics)
### 1. "无限制"方块互换 (滤牌机制)
- **规则**：与传统四消必须"互换后必须产生消除"不同，本作允许玩家**互换任意两个相邻（包含斜向对角线）的方块，无论是否发生消除**。
- **代价**：每一次互换（无论是否消除）都会固定扣除 1 次"剩余步数"。
- **策略深度**：这等同于《小丑牌》中的"弃牌 (Discard)"。玩家可以战略性地消耗步数，将关键颜色的方块运送到特定位置，人为"做牌"，不仅支持横竖相连，还支持**斜向对角线连消**，以达成惊人的 6 连消或引发大型连击雪崩。四消的更高门槛使得每次成功消除都更加有策略意义，玩家需要更深入地思考布局。

### 2. 计分公式：基础分 (Chips) × 倍率 (Mult)
每一次消除独立计算分数，公式如下：
- **基础分 (Chips)**：默认 = 消除方块数量 × 10。
- **基础倍率 (Mult)**：默认 = 消除方块数量 - 1。
- **连击增强 (Combo)**：因方块消除掉落引发的后续连击，每一次连击都会让当前的全局倍率 `+1`。

## 四、 小丑牌系统 (Jokers) — 附着机制
小丑牌是游戏最核心的 Build 来源，它们提供打破规则的被动增益。与传统卡牌游戏不同，本作采用**附着 (Attach) 机制**：

### 附着流程
1. **购买**：玩家在商店花费金币购买小丑牌，购买后进入**背包 (Inventory)**。
2. **附着**：玩家点击背包中的小丑牌，进入**附着模式**，棋盘高亮提示。接着点击棋盘上的任意方块，将小丑牌效果绑定到该方块上。方块右上角会显示对应的小丑牌图标徽章。
3. **触发**：只有当**附着了小丑牌的方块被消除**时，该小丑牌的效果才会生效。
4. **消耗**：小丑牌附着在方块上后，当方块被消除（无论效果是否成功触发），小丑牌同时被消耗销毁。

### 策略意义
- **精准投放**：玩家需要预判哪些方块即将被消除，将小丑牌附着在关键位置以最大化收益。
- **资源管理**：小丑牌是消耗品，需要权衡何时使用、用在哪里。
- **风险与回报**：附着在难以消除的位置可能浪费金币，附着在即将消除的方块上则能立即获得强大加成。
- **可叠加购买**：同一种小丑牌可以重复购买，存入背包叠加使用。

### 小丑牌类型
  - **颜色流派**：如"红莲之心"（附着在红色方块上，消除时倍率+3）、"海蓝宝石"（附着在蓝色方块上，消除时基础分+50）、"虚空之眼"（附着在紫色方块上，消除时最终得分 x1.5）。
  - **形状/规模流派**：如"几何大师"（附着的方块被消除且该组达成 5 连消及以上时，该次消除总分 x2）。
  - **连击流派**：如"多米诺"（附着的方块被消除且当连击数达到 3 及以上时，该次消除总分 x3）。

## 五、 视觉表现与打击感 (Game Feel / Juiciness)
为了突出"数值爆炸"的爽快感，游戏在视觉反馈上进行了重点强化：
1. **附着标记**：
   - 附着了小丑牌的方块右上角会显示一个彩色**徽章图标**，不同类型的小丑牌有不同的颜色和符号标识，一目了然。
   - 进入附着模式时，棋盘边框高亮为粉红色，所有方块呈现脉动动画提示可点击。
2. **小丑牌触发反馈**：
   - 当附着了小丑牌的方块被消除且触发条件达成时，该方块会发射出与其代表颜色相关的**光球粒子 (Particle)**，沿曲线轨迹飞向同组其他被消除的方块。
3. **赋能状态 (Empowered)**：
   - 当粒子击中方块后，方块不会立刻消失，而是会爆发一圈"冲击波 (Impact Ring)"。
   - 随后，这组方块进入 400ms 的"赋能高亮"状态（放大、高光、抖动），暗示它们正在吸收小丑牌的数值加成。
4. **延迟结算与粉碎**：
   - 欣赏完方块被强化的状态后，系统瞬间计算出夸张的 `Chips x Mult`，并在方块上方弹出巨大的飘字，最后方块粉碎消失。
5. **重力掉落动画**：上方的方块掉落填补空缺时，会有轻微的物理弹跳效果 (Bounce)，增加盘面的活力。

## 六、 未来扩展方向 (Roadmap)
在当前原型基础上，未来可扩展以下系统：
1. **塔罗牌 / 消耗品**：允许在局内使用一次性道具（如：将选中方块变色、炸毁特定方块、增加临时步数）。
2. **星球牌 / 升级机制**：花费资源永久提升某种特定消除（如：四连消、L型消、六连消）的基础 Chips 或 Mult。
3. **特殊方块材质**：除了颜色，方块可以被镀层（如：玻璃方块消除时倍率翻倍但会冻结周围方块；钢铁方块留在场上每回合提供固定加成）。
4. **Boss 盲注限制机制**：每 3 关遇到一个 Boss 盲注，带有负面规则（如：禁用某颜色计分、方块随机变色、禁止某种互换等）。
