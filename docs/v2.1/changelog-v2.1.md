# 变更日志 - v2.1

## 需求背景

当前版本的计分逻辑不够清晰：
- 以"消除组"为单位统一计算分数，无法区分每个方块的贡献
- 基础倍率混合了消除数量和连击数，概念模糊
- 浮动文字只显示 `chips x mult`，无法体现卡牌加成
- 玩家难以理解自己的分数是怎么算出来的

v2.1 的目标是**明确消除后的分数计算流程**，让每个方块独立计分，计分公式清晰可预期。

---

## 功能变更点

### 1. 新计分公式

**单方块得分**：
```
单方块得分 = (基础分 + 基础分加成) × (基础倍率 + 倍率加成)
```

- **基础分**：可配置项，写在 `config.js` 中（如 `BASE_CHIP = 10`）
- **基础分加成**：该方块上附着的卡牌效果带来的（如海蓝宝石 +50、黄金之风 +60）
- **基础倍率**：由本次消除涉及的方向数决定（针对整次消除，所有方块统一）：
  - 仅单方向（横/竖/斜其一）→ **1 倍**
  - 两个方向（横+竖 / 横+斜 / 竖+斜）→ **2 倍**
  - 三个方向（横+竖+斜）→ **3 倍**
- **倍率加成**：该方块上附着的卡牌效果带来的（如红莲之心 +3、翡翠之叶 +4、虚空之眼 +5、几何大师 +6、多米诺 +8）

**一次消除总分** = 所有被消除方块的单方块得分之和

### 2. 小丑牌效果统一为两类

所有小丑牌效果统一为**基础分加成**或**倍率加成**，不再有乘法类：

| 小丑牌 | 效果类型 | 加成 |
|--------|---------|------|
| 红莲之心 | 倍率加成 | Mult +3 |
| 海蓝宝石 | 基础分加成 | Chips +50 |
| 翡翠之叶 | 倍率加成 | Mult +4 |
| 黄金之风 | 基础分加成 | Chips +60 |
| 虚空之眼 | 倍率加成 | Mult +5 |
| 几何大师 | 倍率加成 | Mult +6（5连消及以上时触发） |
| 多米诺 | 倍率加成 | Mult +8（连击数>=3时触发） |

### 3. config.js 新增配置项

- `BASE_CHIP`：每个方块的基础分（默认 10）
- 移除旧的按消除数量计算 chips 的逻辑

### 4. 移除连击（combo）计分

- 连击不再参与分数计算
- 移除 `comboCounter` 对 mult 的加成
- 连击仅作为视觉反馈保留（连锁消除动画）
- 注意：多米诺的触发条件"连击数>=3"仍保留，但效果改为倍率加成

### 5. 基础倍率判定逻辑

基础倍率的判定基于**被移动的方块**是否处于多方向匹配的交叉点：

1. 记录玩家本次移动的方块坐标（即 `onCellClick` 中被交换的目标方块）
2. 消除检测后，检查**被移动的方块**参与了哪些方向的匹配：
   - 该方块是否出现在某个**水平方向**的 4 连匹配中
   - 该方块是否出现在某个**垂直方向**的 4 连匹配中
   - 该方块是否出现在某个**对角线方向**的 4 连匹配中
3. 该方块参与的方向数即为基础倍率（1/2/3）
4. **连锁消除**（非玩家主动移动触发）没有"被移动的方块"，基础倍率固定为 1

### 6. 计分展示面板（新增 UI）

在棋盘旁（或下方）新增一个**计分展示面板**，每次消除时实时展示完整的计分过程，让玩家清晰感知到多方向消除和各种卡牌效果的生效。

#### 展示时机
- 每次消除触发时，面板亮起并逐步展示计分过程
- 消除结束后面板淡出或保持到下一次消除

#### 展示内容（逐行展开，带动画）

**第一行：方向判定**
- 显示本次消除涉及的方向，例如：
  - `横向消除 → 基础倍率 ×1`
  - `横向 + 竖向消除 → 基础倍率 ×2`
  - `横向 + 竖向 + 斜向消除 → 基础倍率 ×3`

**第二行起：逐方块计分明细**
- 每个被消除的方块显示一行，例如：
  - 无卡牌：`🟥 基础分 10 × 倍率 2 = 20`
  - 有基础分加成卡牌：`🟦 (10 +50 ♦海蓝宝石) × 倍率 2 = 120`
  - 有倍率加成卡牌：`🟥 基础分 10 × (2 +3 ♥红莲之心) = 50`
  - 两者都有：`🟥 (10 +50 ♦) × (2 +3 ♥) = 300`
- 有卡牌加成的部分用对应卡牌颜色高亮，让玩家一眼看出哪张卡牌生效了

**最后一行：总分汇总**
- `本次消除总分：+XXX`
- 数字用放大+弹跳动画强调

#### 展示节奏
- 方向判定行先出现（约 300ms）
- 逐方块明细依次弹出（每行间隔约 150ms）
- 总分汇总最后出现，带数字滚动动画（约 500ms）
- 整个面板展示约 2~3 秒后自动淡出

#### 移除旧浮动文字
- 不再在方块上方弹出 `chips × mult` 浮动文字
- 所有计分信息统一在计分展示面板中呈现
